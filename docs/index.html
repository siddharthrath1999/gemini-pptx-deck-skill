Better prompts

Clear beats long.

More context isn't better context. Unrelated details pull slides off topic, and conflicting asks force guesses. Give the skill the few things only you know; it handles research, structure and design.

groups

Say the job

Who it's for and what they should decide or learn. That one line shapes the structure more than anything else.

verified

Give the source of truth

Attach the files that matter. One right document beats ten loosely related ones, and it outranks the web.

checklist

Name the must-haves

Length, sections you need, things to avoid. Skip adjectives like "amazing"; they don't change the result.

warningLong but unclear

Questions

Good to know.

Is it really free?add

Yes. PPTX Native is open source under the MIT licence. To use it in the Gemini app you need a Google AI Pro or Ultra plan, because it runs in Task mode. In Antigravity, your usual Antigravity plan applies.

Why does it need Task mode in Gemini?add

Task mode gives Gemini a small computer where it can run the skill's tools. In normal chat it can't, so you'd get text, HTML or a Google Slides export instead of a .pptx.

Can it edit a deck I already have?add

Yes. Attach the .pptx and say what to change. It can rewrite text, update tables and chart data, replace notes, reorder or delete slides, and redesign or add slides in your deck's own fonts and colours. New and redesigned slides need a 16:9 deck.

Can I edit everything it makes?add

Yes. Every text box, shape, chart and table is a normal PowerPoint object, and charts keep their data.

Are the numbers right?add

It researches and cites sources, but it can still pick a weak source or misread one. Check figures before you present. The handoff note lists every source.

Can it use my brand?add

Give your colours as hex codes in the prompt. Fonts default to ones every device has; ask for a brand font only if everyone presenting has it installed.

Does it add photos?add

No. Visuals come from charts, tables, shapes and icons. Add your own photos afterwards.

Upload says "did not pass the security scan".add

Upload the official zip, unchanged. If you edited files inside it, undo the changes and try again.

Is this made by Google or Microsoft?add

No. PPTX Native is an independent open-source project. Gemini, Antigravity and PowerPoint logos appear only to show where the skill works and what it makes.
