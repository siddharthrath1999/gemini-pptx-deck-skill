How it works

A skill is a set of instructions and tools you add to Gemini once. After that, Gemini uses it whenever you ask for slides. This one comes with a small design engine, so the slides are real PowerPoint objects, not pictures or web pages.

1. Research

Reads your files and searches the web for facts, and keeps track of where each number came from.

2. Story

Plans the parts and writes one clear headline per slide, so the headlines alone tell the story.

3. Design

Picks colours, fonts and a slide style that suit your audience, and the best layout for each slide.

4. Build

Creates the .pptx with native charts, tables, icons and speaker notes.

5. Check

Automatically checks every slide for cut-off text, overlaps, hard-to-read colours and AI-sounding phrases. Then it looks at pictures of the slides and fixes problems.

6. Deliver

Gives you the file plus a short note: what it assumed, any gaps to fill, and its sources.

Set up (about 2 minutes)

What you need

  • A personal Google account (not work or school), age 18 or over
  • A Google AI Pro or Ultra plan, because the skill runs in Task mode
  • Keep Activity turned on in Gemini, and Personal Intelligence switched on for tasks
  • The Gemini website or the Gemini Mac app to upload the skill (you can use it on your phone afterwards)

Task mode is not offered in the European Economic Area, the UK, Switzerland or Nigeria.

  1. Download the skillGet build-pptx-deck.zip from the button above. Don't unzip it.
  2. Open Skills in GeminiAt gemini.google.com, click Customise in the left menu, then the Skills tab.
  3. UploadClick Create, then Upload, and choose the zip file.
  4. ConfirmCheck the name says build-pptx-deck and click Create. Done.

Make a deck

  1. Start a new chat and choose a strong modelPick 4 Argon in the model menu if you have it.
  2. Switch to TaskClick Task under the message box. This matters: in normal Chat mode Gemini can't run the skill's tools, so you'd get text, HTML or Google Slides instead of a .pptx.
  3. Ask for your deckJust describe what you want. Gemini picks the skill on its own, or type @ (or /) and choose build-pptx-deck to be sure.
  4. Wait, then downloadA 40 to 60 slide deck can take a while because Gemini researches, builds and checks it. You can leave the page; tasks keep running. Click the file to download it.
  5. Ask for changes in the same chatFor example: "Make slide 12 a chart", "Use our brand colours", or "Add a section on pricing". It rebuilds only what you mention.

Write better prompts

A one-line request works. Adding a few details gets you a deck that fits your situation better. Think of it as briefing a colleague.

Add your files

Attach PDFs, spreadsheets, notes or old decks to the same message. Gemini uses them first and searches the web only for what's missing. Connected apps like Google Drive and Gmail work too.

Say the length

Without a number it plans a thorough deck: about 40 to 80 slides for an analysis, 12 to 25 for a pitch. Say "short" or give a number if you want less.

Set the look

Name a mood ("calm and premium", "playful", "dark and techy") or give colours as hex codes. Without this, it picks a look that suits the topic.

Point at what matters

Name the companies, regions, time period or questions you care about. Specific asks get specific slides.

Ask for the format you need

"Speaker notes in Hindi", "no quiz slides", "appendix with full tables", "one slide per company". It follows instructions like these.

Read the handoff note

It lists what Gemini assumed, any gaps marked like [2025 revenue], and its sources. Fill the gaps before you present.

Good to know

Check the numbers

Gemini researches carefully and cites sources, but it can still pick a weak source or misread one. Verify any figure you'll present or decide on.

Fonts work everywhere

It uses fonts every device has (Arial, Georgia, Calibri and similar), so the deck looks the same on Windows, Mac, phones and Google Slides. Custom brand fonts only if you ask.

No photos

Visuals come from charts, tables, shapes and icons. It doesn't generate or insert images. Add your own photos in PowerPoint afterwards.

Task mode uses your plan's limits

Long decks use more of your Gemini allowance. If you hit the limit, try again later or ask for a shorter deck.

If something goes wrong

What you seeWhat to do
You get text, HTML, a Canvas page or Google Slides, not a .pptxStart a new chat, click Task before you send, and mention the skill with @.
"Skill name already exists" when uploadingYou already have it. To update, open the skill, click More, then Replace skill.
"The uploaded file did not pass the security scan"Use the zip from the official download, unchanged. If you edited the files, undo your changes and try again.
The handoff note says the render check was skippedThe deck still passed the automatic checks. Open it and skim the slides, or ask Gemini to try the render check again.
A slide looks crowded or a chart is wrongTell Gemini the slide number and what to change, in the same chat.
The skill isn't used at allCheck it's switched on in Customise, then Skills. Type @ and pick it by name.
